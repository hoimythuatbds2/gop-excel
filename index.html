Công cụ gộp file Excel khối lượng

Chọn từ 2 file trở lên (2, 3, 4... file đều được), công cụ tự gộp và cho xem trước. Hài lòng thì bấm tải về. Dữ liệu xử lý ngay trên máy bạn, không gửi đi đâu.

Xem trước file tổng hợp (dòng tô vàng là dòng đã được gộp)
Quy tắc gộp
  1. Các sheet của các file được ghép với nhau theo Tháng/Năm ghi trong sheet (T10 với T10, T11 với T11...); nếu không đọc được thì ghép theo tên sheet. Sheet chỉ có ở 1 file vẫn được đưa vào.
  2. Biển số (cột B) giống nhau thì gộp thành 1 dòng, số liệu từng ngày được cộng lại. Không phân biệt chữ hoa/thường, dấu gạch ngang, khoảng trắng (98H05759 = 98H-05759).
  3. Biển chỉ có ở 1 file vẫn được đưa vào file tổng hợp. Số file không bị giới hạn, biển nào xuất hiện ở bao nhiêu file thì số liệu được cộng từng ấy.
  4. Tổng KL = tổng chuyến × khối lượng mỗi chuyến (xe), hoặc bằng tổng số (tàu không có khối lượng). Cùng 1 biển có nhiều mức khối lượng thì KL cộng riêng từng mức.
  5. Dòng tổng ở cuối bảng và các cột tính nháp bên phải không được lấy; file tổng hợp tự tính lại tổng.

Cần có mạng internet khi mở công cụ này (để tải thư viện đọc/ghi Excel).
